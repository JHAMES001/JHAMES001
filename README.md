## 🚀 Featured Projects

### [MICHI — Real-Time AI Voice Translator](https://github.com/JHAMES001/turn-based-ai-translator)
A turn-based, two-person AI translator that lets two people hold a real-time conversation across language barriers using a single phone. Built collaboratively with [@chzn-ichi](https://github.com/chzn-ichi).
- **Stack:** JavaScript · Groq API (Llama 3.3 70B) · Web Speech API · Netlify Functions
- **Highlights:** State-machine architecture, secure server-side API key handling, ~70 language support with live speech recognition
- 🔗 [Live demo](https://michitranslate.netlify.app)

### [Notecast — Document-to-Audio Web App](https://github.com/JHAMES001/notecast)
Converts documents into narrated audio with an interactive quiz mode for active recall.
- **Stack:** JavaScript · Groq LLM backend · Web Speech API · Vercel
- **Highlights:** End-to-end pipeline from raw document to audio + auto-generated comprehension quiz
